# Onboarding

Welcome to the MACC Lab. Complete this checklist when you join the lab.

## New student checklist

### Accounts and access

- [ ] Request a cluster account (see [Accounts](../getting-started/accounts.md))
- [ ] Confirm SSH access (see [SSH Access](../getting-started/ssh.md))
- [ ] Request access to the lab GitHub organization
- [ ] Join any relevant lab Slack or communication channels (ask your PI)

### Documentation and policies

- [ ] Read the [Data Storage Rules](data-storage-rules.md)
- [ ] Read the [GitHub Workflow](github-workflow.md)
- [ ] Review the [HPC overview](../hpc/index.md)
- [ ] Review the [Slurm guide](../hpc/slurm.md)

### First technical steps

- [ ] Complete the [First Login Checklist](../getting-started/first-login.md)
- [ ] Set up a Python environment (see [Python guide](../software/python.md))
- [ ] Submit a small test Slurm job
- [ ] Confirm access to project storage

### Data policy

- [ ] Acknowledge the lab data storage policy (confirm with PI)
- [ ] Confirm which storage locations are approved for your project data

## Questions

Ask your PI, labmates, or the lab administrator if you have questions during onboarding.
