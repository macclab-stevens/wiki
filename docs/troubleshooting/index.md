# Troubleshooting

This section provides troubleshooting guides for common issues with MACC Lab computing resources.

## Sections

- [Open OnDemand](open-ondemand.md)
- [Slurm](slurm.md)
- [Python Environments](python-environments.md)
- [GPU](gpu.md)

## General troubleshooting steps

1. Check error messages carefully — they usually indicate the root cause
2. Review relevant documentation section first
3. Check job logs if the issue is with a Slurm job
4. Search this documentation for the error message or symptom
5. Ask a labmate or the lab administrator if the issue persists

## What to include when asking for help

- Command run
- Full error message
- Job ID, if relevant
- Node name, if relevant
- Environment name
- Approximate time of failure
